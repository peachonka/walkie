## Запуск серверной части

### Требования

Для работы серверной части необходимы:

- Ubuntu 24.04 LTS;
- Node.js;
- PostgreSQL 16;
- PM2;
- Git.

### 1. Получение исходного кода

Клонировать репозиторий проекта и перейти в директорию серверной части:

```bash
git clone <ссылка-на-репозиторий>
cd <путь-к-проекту>/backend
```

### 2. Установка зависимостей

Установить зависимости Node.js:

```bash
npm install
```

### 3. Настройка базы данных

Убедиться, что PostgreSQL запущена:

```bash
sudo systemctl status postgresql
```

При необходимости запустить сервис:

```bash
sudo systemctl start postgresql
```

База данных и пользователь должны быть предварительно созданы, а схема базы данных должна быть применена.

### 4. Настройка переменных окружения

Создать файл `.env` в директории backend и указать параметры подключения к базе данных и необходимые настройки приложения.

Пример конфигурации:

```env
DB_HOST=localhost
DB_PORT=5432
DB_NAME=walkie
DB_USER=<имя-пользователя>
DB_PASSWORD=<пароль>

PORT=<порт-сервера>
```

Значения параметров должны соответствовать настройкам PostgreSQL и серверной части проекта.

### 5. Запуск серверной части

Для запуска сервера используется PM2.

Запустить приложение:

```bash
pm2 start server.js --name walkie-backend
```

Сохранить конфигурацию запущенных процессов:

```bash
pm2 save
```

Для автоматического запуска процессов после перезагрузки сервера настроить автозапуск PM2:

```bash
pm2 startup
```

Выполнить команду, которую PM2 выведет в терминал, и повторно сохранить список процессов:

```bash
pm2 save
```

### 6. Проверка работы

Проверить состояние процесса:

```bash
pm2 status
```

Просмотреть журналы сервера:

```bash
pm2 logs walkie-backend
```

Для проверки API можно использовать Swagger UI по адресу:

`http://<адрес-сервера>:<порт>/api-docs`

### 7. Обновление серверной части

Для обновления серверной части после внесения изменений в репозиторий:

```bash
git pull
npm install
pm2 restart walkie-backend
```

После перезапуска проверить состояние процесса:

```bash
pm2 status
pm2 logs walkie-backend
```
